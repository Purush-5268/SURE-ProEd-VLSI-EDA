# SURE ProEd Cloud VLSI Workspace

This repository provides a fully automated, browser-based VLSI design environment for SURE ProEd students. By utilizing GitHub Codespaces, it provisions a complete RTL-to-GDS open-source toolchain with a built-in graphical desktop—requiring zero local storage or installation.

## How to Start Your Lab
1. Click the green **Code** button at the top right of this page.
2. Select the **Codespaces** tab.
3. Click **Create codespace on main**.
4. Wait for the cloud machine to build (this takes a few minutes the very first time).
5. Once VS Code loads in your browser, click the **Ports** tab near the bottom terminal panel.
6. Click the globe icon next to **Port 6080 (noVNC Desktop)** to open your Linux graphical interface in a new tab.
